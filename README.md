# Meal Suggest

## This project was made for a college class

Link to repo: https://github.com/JSchellRoseBank/Meal-Suggest

Link to youtube video: https://youtube.com/shorts/qhfNzFupAqo?feature=share

## Purpose
The purpose of the app is to provide meal suggestions to users that are looking for meal options for different times of day.
The times of day are as follows:
- Morning
- Mid morning
- Afternoon
- Mid afternoon
- Evening
- Late evening

## Design Considerations
The inputs and buttons are position at the top of the screen so that when the keyboard pops up it isn't in the way of the suggestions and the error message.
